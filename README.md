Savoria — Modern Responsive Restaurant Website

A modern, elegant, and fully responsive multipage restaurant website built with HTML, CSS, and JavaScript.

Savoria is designed for restaurants, cafés, food businesses, and dining brands that want a stylish online presence with smooth animations, interactive menus, and a responsive user experience.
